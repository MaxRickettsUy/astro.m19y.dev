# m19y.dev

Personal site — links, projects, and yearly read/watch/listen logs.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com), deployed on [Netlify](https://netlify.com).

## Development

```bash
npm install
npm run dev       # localhost:4321
npm run build     # build to ./dist/
npm run preview   # preview production build
```

See [CLAUDE.md](./CLAUDE.md) for architecture details and development conventions.
